- define MVP scope
- define an explicit not-doing list

- ask focused HITL checkpoints at key moments:

  2. after option comparison
  3. before finalizing the recommended direction

- steps
- key decisions
- edge cases
- tests/validation
- risks/tradeoffs
- likely impacted files/components
